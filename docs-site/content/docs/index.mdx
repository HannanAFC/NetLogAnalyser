NetLogAnalyser analyser is a powerful platform that allows for the real-time ingestion and analysis of network logs, flagging logs
which may be anomalous and providing anomaly scores with reasoning.

## How it works

You can send network logs to the platform via its ingest API, this allows for continous streams of network logs to be sent and
inspected immediately. All of this is presented via a detailed and analytical dashboard, which provides key information at a glace.

## Open source and self-hostable

In addition, the platform is entirely self-hostable and open source. You can host the entire platform stack by executing a single
install script. The platform is open source so you can inspect and modify the code as you desire.
