# Phase 4 - Log scanning and processing

## Goal
Create anomaly analysis system:
- Scan job model.
- Scan endpoint.
- Scan job tracking:
    - Pending.
    - Processing.
    - Complete.
    - Failed.
- Parser for the file format the analyser ends up using.
- Preprocessing and feature extraction pipeline.
- Initial anomaly model integration.
- Store generated results.

By the end of this phase, there should be a working, basic log uploading system that scans for anomalies.
