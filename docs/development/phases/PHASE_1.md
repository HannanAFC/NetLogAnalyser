# Phase 1 - Foundation

## Goal
Get the project into a state were:
- The frontend exists and is deployed.

- The backend exists and is deployed.

- The backend can connect to the database.

- The frontend can talk to the backend.

- The project has environment/config handling.

- There is a basic health route and a basic frontend route.

- Deployment Targets:
    - Deploy the frontend on Render.
    - Deploy the backend on Render.
    - Integrate with GitHub actions for automated CI/CD.

- Make sure database migrations work correctly and that there is a proper process setup for this.

The foundations of the project must be laid and there should be a decent pipeline for deploying changes.
